## Как пользоваться на защите (этап 2)

Вопрос «почему принято такое решение?» закрывается ссылкой на ADR:
ответ опирается на Контекст (ограничение из бизнес-целей [А-01](../../stage1-concept/01-business-goals.md),
НФТ [А-09](../../stage1-concept/09-nonfunctional-requirements.md) или ФТ
[А-02](../../stage1-concept/02-functional-requirements.md)), а не на
соображения в момент разговора.
