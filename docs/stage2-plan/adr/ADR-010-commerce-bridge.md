# ADR-010: Commerce Bridge — контракт с приложениями компании

**Статус**: Принято · Этап 1
**Контекст**:
- Ц-2: монетизация через существующие приложения покупки (FR-10),
  встраивать e-commerce внутрь нельзя (дублирование, юрисдикция оплат,
  чужие релизные циклы).
- B-03: внешний API может быть недоступен/меняться — нужна деградация.
- T-10: интеграции — вектор атак (12.5: компрометация ключей,
  скрейпинг каталога).

**Решение**:
1. **Только публичный контракт**: REST API/SDK приложений компании
   (версионирование `/v1`, окно поддержки ≥ 2 версий) + deep links для
   перехода «товар → экран покупки»; внутренние сервисы магазина
   недоступны напрямую.
2. **Commerce Bridge** — домен SportSphere, единственная точка
   интеграции: формирует ссылки с источником (`source=workout_hint`,
   `promo_banner`, `group_post`), принимает подтверждение перехода
   и события конверсии.
3. **Защита контракта**: mTLS + подпись запросов (HMAC), ротация
   ключей, квоты на стороне магазина (закрывает T-10 из 12.5).
4. **Устойчивость**: circuit breaker с полукругом; при недоступности —
   подсказки и покупка деградируют до резервного сценария (in-app
   баннеры промо), остальные функции не страдают (наработки 10.5).
5. **Сверка атрибуции**: переходы → журнал событий; после покупки
   магазин пушит конверсию; сверочный джоб сверяет цепочку
   (at-least-once → идемпотентность, ADR-004) — цифры Ц-2 достоверны.

**Последствия**:
- (+) Цель Ц-2 реализуема без постройки магазина внутри; команда
  магазина работает в своём контуре (удовлетворяет А-03).
- (+) Узкая поверхность атаки — один домен и один контракт.
- (+) Деградация локальна и предсказуема (B-03 закрыт).
- (−) Конверсия зависит от чужого UX и скорости их релизов: ежемесячная
  сверка метрик с командой магазина, общая таблица целей Ц-2.
- (−) Дополнительный сетевой hop в сценарии покупки — терпимо:
  переход — не в тёплом пути экрана, а в момент действия пользователя.

**Связи**: Ц-2, ФТ FR-04/FR-08/FR-10, КС-2/КС-6; [А-14a](../views/functional.md);
ADR-005 (квоты на шлюзе), ADR-009 (ключи партнёров); практики `10.5`, `12.5`.
