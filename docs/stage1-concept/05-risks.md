# А-05. Описание рисков реализации (бизнес и технические)

> Этап 1 · Утверждение концепта. Пункт развивается: на этапах 2–3
> дополняется — см. пересмотр в А-15.

Шкала: вероятность и влияние — **В**ысокая / **С**редняя / **Н**изкая.
Приоритет риска = Вероятность × Влияние. Формат: «что будет → как
адресуется архитектурой».
