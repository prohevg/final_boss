# А-09. Анализ и список нефункциональных требований

> Этап 1 · Утверждение концепта. НФТ выведены из контекста задания,
> особенностей и атрибутов качества [А-08](08-quality-attributes.md);
> каждое проверяемо (имеет меру приёмки).

## Источники НФТ

- Контекст: глобальные пользователи, 2 облака, распределённая
  мультиязычная команда, эксперименты.
- Особенности: нет сети в «диких» местах, массовые старты, устройства,
  fitness-функции телефона, охрана данных, неравнозначность требований.
- Цели и АК: [А-01](01-business-goals.md), [А-08](08-quality-attributes.md).

## Список требований

| ID | НФТ | Мера приёмки | Источник |
|----|-----|--------------|----------|
| NFR-01 | **Отзывчивость** интерактивных сценариев | p95 ≤ 300 мс (API экрана), лента ≤ 500 мс, поиск ≤ 500 мс; без критических блокировок UI | Ц-1 |
| NFR-02 | **Доступность** | 99,9 %/мес по внешнему API; плановое обновление без простоя (rolling, blue-green для критичных) | АК-1 |
| NFR-03 | **Масштабируемость** | горизонтальная: ×10 пик ≤ 3 мин; горизонтальное шардирование данных по пользователю; вертикальные лимиты не используются как единственная модель | Особенность 2, АК-1 |
| NFR-04 | **Приватность, безопасность и комплаенс** | residency PII; шифрование at rest/in transit; согласия (Art. 9), возрастной режим; выгрузка ≤ 30 дней, удаление ≤ 7 дней; аудит доступа | Особенность 5, Ц-4 |
| NFR-05 | **Локализация и глобальность** | интерфейс и контент ≥ 30 языков, RTL, региональные шаблоны; сервисы доступны без гео-блокировок (в т.ч. для временных посетителей регионов) | Особенность 1, контекст |
| NFR-06 | **Офлайн-устойчивость** | запись тренировок без сети ≥ 24 ч; синхронизация без потерь при обрывах (0 потерянных, дубли ≤ 0,01 %) | Особенность 1, FR-14 |
| NFR-07 | **Наблюдаемость** | 100 % сервисов: метрики/логи/трассы (OTel); MTTD ≤ 5 мин, MTTR ≤ 30 мин; PII не попадает в телеметрию (фильтр на агенте) | АК-3, 15.6 |
| NFR-08 | **Производительность на клиентах** | размер приложения ≤ 180 МБ; расход батареи в фоне ≤ 5 %/час тренировки; поддержка устройств ≥ 5 лет назад (средний сегмент) | Контекст (разные устройства) |
| NFR-09 | **Надёжность и восстановление данных** | RPO ≤ 15 мин, RTO ≤ 2 ч для региона; бэкапы 3-2-1; регулярные прогоны восстановления (ежеквартально) | Особенность (нет единого облака), 14.5 |
| NFR-10 | **Безопасность контента и модерация** | 100 % публикаций проходят автофильтр; время реакции на жалобу ≤ 30 мин в активные часы; приоритет ревью — контент несовершеннолетних | Ц-4, FR-01 |
| NFR-11 | **Портируемость (нет vendor lock-in в ядре)** | ядро разворачивается в любом из 2 провайдеров из одного GitOps-контура; запрет SDK провайдера в доменах (контроль — архитектурное ревью) | Контекст (нет выбранного провайдера), АК-1 |
| NFR-12 | **Доступность интерфейса (a11y)** | WCAG 2.1 AA для основных экранов (запись тренировки, статистика, группа), поддержка скринридеров и динамического шрифта | Ц-4 «спорт для каждого» |

## Классификация по срочности

- **Обязательны для релиза (MVP)**: NFR-01, NFR-02, NFR-04, NFR-06,
  NFR-07 (базовый контур), NFR-11.
- **К фазе 2**: NFR-03 (пиковые режимы), NFR-09 (полный DRP), NFR-10
  (масштаб модерации).
- **К фазе 3–4**: NFR-05 (полный объём языков), NFR-08 (оптимизация
  старых устройств), NFR-12 (углублённый аудит a11y).

## Взаимосвязи и напряжения

| Напряжение | Разрешение |
|------------|------------|
| NFR-03 (пик ×10) ↔ NFR-02 (доступность без простоя) | эластичность без оверпревью: контейнеры + KEDA; выделенные кластеры только для соревнований (А-16) |
| NFR-04 (residency) ↔ NFR-01 (отзывчивость) | тёплые данные региона + кэши; PII-хранилище в своём контуре (ADR-003) |
| NFR-07 (полные логи) ↔ NFR-04 и стоимость | классификация и retention логов, PII-фильтр на агенте (15.6) |
| NFR-11 (портируемость) ↔ скорость разработки | отказ от SDK провайдера — цена за независимость от best-of-breed выбора (ADR-002) |

## Проверка покрытия особенностей

| Особенность | НФТ |
|-------------|-----|
| Пользователи по всему миру, дикие места | NFR-05, NFR-06 |
| Массовые соревнования | NFR-03 (+ NFR-01, NFR-02) |
| Сторонние устройства | NFR-08 (клиент), FR-09 (ФТ) |
| Fitness-функции телефона | FR-12 (ФТ), NFR-08 |
| Охрана данных | NFR-04 (+ NFR-10 для контента) |
| Не всё одинаково важно | классификация выше; экономия — в [А-06](06-roadmap.md) и А-16 |
